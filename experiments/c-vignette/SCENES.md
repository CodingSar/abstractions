# Scenes

Every vignette, grouped by effect. Each row is the file's `situation`; the file holds the cues and the scene. The rows are a copy of front matter, kept so selection reads one file; regenerate after any edit with `grep -H '^situation:' vignettes/*.md`.

## explore: explore without flailing

- `vignettes/tracer-bullet.md`: handed a large unfamiliar system and asked how one thing moves through it
- `vignettes/frontier.md`: asked to find where something happens in a codebase too large to read
- `vignettes/history-first.md`: facing code that looks pointless, dead or wrong, before deciding what it is for

## foresee: see the failure before it happens

- `vignettes/premortem.md`: about to run a multi-step plan whose failure is costly to undo
- `vignettes/red-first.md`: about to fix a bug whose cause looks obvious
